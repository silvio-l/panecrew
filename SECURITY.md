# Security Policy

Panecrew is maintained by a single person, best-effort, alongside other work. There is no SLA and
no guaranteed response time — but security reports are taken seriously and prioritized over other
work.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability. Instead, report it privately via
[GitHub Security Advisories](https://github.com/silvio-l/panecrew/security/advisories/new).

Include, if possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- The version(s) affected

There is no guaranteed acknowledgment or fix timeline — this is a solo-maintained, best-effort
project — but every report will be read and taken seriously.
