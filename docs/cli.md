## `panecrew`

Panecrew — a grid of live terminal panes with a focus-following file explorer

**Usage:** `panecrew [PROJECT_PATH]`

###### **Arguments:**

* `<PROJECT_PATH>` — Open directly with this project instead of showing the project picker.

   Resolved against the current shell's working directory if relative. A `~` is expanded by your shell before PaneCrew ever sees it; if the path doesn't exist or isn't a directory, PaneCrew falls back to the picker rather than failing to start.
