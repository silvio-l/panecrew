# PaneCrew Desktop

Tauri 2 + React/TypeScript + Tailwind + Radix UI, `portable-pty` on the Rust side. See the repo root
`README.md` for product context.

## Recommended IDE Setup

Any editor with TypeScript + Rust support works. Recommended: a [Tauri](https://tauri.app/) extension
for your editor of choice plus [rust-analyzer](https://rust-analyzer.github.io/).
