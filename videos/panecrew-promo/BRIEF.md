## Intent

A short promo for PaneCrew, a VS Code extension that turns the editor into a
grid of simultaneously visible terminal panes (one per project) paired with a
file explorer that automatically follows whichever pane has focus. Audience:
developers evaluating it on the VS Code Marketplace or the product website.
Tone: confident, clean, product-craft — closer to a polished dev-tool teaser
than a hype reel. No stock footage, no invented UI — every visual is a real
captured screenshot of the actual extension running.

## Assets

- assets/screenshots/hero-grid.png — quad terminal grid (extension/website/panecrew-src panes) with the PaneCrew explorer open on the panecrew root, showing a git-status badge. Opening/hero beat: "run every project, side by side."
- assets/screenshots/focus-follow.png — explorer switched to the "website" project right after that pane was focused. Differentiation beat: "the explorer follows you."
- assets/screenshots/git-status.png — explorer showing a stable single git-status badge (NOTES.md, untracked). Craft beat: "know what's dirty at a glance."

## Customizations

- Ken Burns / reveal motion on each screenshot (slow scale + pan), not static cuts.
- Closing brand card: "PaneCrew" wordmark + tagline, amber-on-indigo per the
  product's brand system (warm amber-gold accent on dark indigo ground).

## Notes

- Screenshots were captured on Windows after PaneCrew's own "Compact Look"
  feature decluttered the window (collapsed menu bar, relocated activity bar,
  cleared title-bar chrome) specifically so they read as close to native
  macOS VS Code as possible — do not crop or mask any part of them.
- No narration/voiceover for this pass — typographic captions carry the
  message. No music sourced either; silent-safe (captions don't depend on
  audio).
